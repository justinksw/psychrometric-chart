# Psychrometric Chart

Mobile-first psychrometric chart + MVAC process path (HK office / public teaching demo).

**Live:** https://justinksw.github.io/psychrometric-chart/

Built from Celine `brief-v3` (light v2) + Beatrice calc (Magnus / ω / enthalpy / wet-bulb). EN primary, °C + g/kg. OA: DB+RH or DB+WB. Free tools only.

## Open locally

```bash
python3 -m http.server 8080 --directory .
```

## Notes

- Demo defaults are teaching values, not a Code of Practice extract.
- Substance: `briefs/ANSWERS-beatrice.md` · Design: `briefs/brief-v3.md` · Direction: `briefs/direction-v2.md`
